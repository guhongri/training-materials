# Training Materials

Public, web-based technical training materials for graduate students working in mechatronics, robotics, instrumentation, and experimental research.

## Available material

- [How to Do an Experiment](how-to-do-experiment/): a 20-slide HTML presentation covering experimental architecture, measurement planning, automation, DAQ-centered acquisition, synchronization, raw-data preservation, auditable processing, repeatability, and reproducibility.

The repository landing page is designed to accommodate additional training websites in separate folders.
