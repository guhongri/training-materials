Experimental Design: Control, Vary, Measure, Monitor

CategoryMeaningExample
Control variableHeld constantProbe position, geometry
Independent variableIntentionally variedCurrent amplitude, frequency
Dependent variableMeasured responseForce, displacement
Disturbance / confounderNot intentionally varied but may affect the resultTemperature, drift
MetadataRequired for reconstructionSample ID, calibration, setup version
Technical principle

Every relevant parameter must either be controlled or accurately monitored, so the actual condition can be reconstructed and incorporated into later analysis.

Operational rule

Control critical variables; measure relevant disturbances; document the rest.

No influential parameter should remain unknown.

Synchronization Across Multiple Devices

DAQ-connected sensors
→
Shared physical event
→
External device / camera
Map every device to DAQ time
\[t_{\mathrm{external}}\rightarrow t_{\mathrm{DAQ}}\]
\[t_{\mathrm{camera}}=a\,t_{\mathrm{DAQ}}+b\]
b start offseta relative clock drift

One marker estimates b; two markers estimate both a and b.

Choose accuracy from the process timescale
  • Camera: typically 60–120 fps
  • DAQ: typically ~1 kHz
  • Start synchronization may be sufficient for short, slow recordings
  • Hardware trigger is preferred when timing error matters
  • Optical flash is a practical shared event
  • A second marker quantifies long-duration drift
First determine whether the timing mismatch changes the scientific result; then select the synchronization method and accuracy.

Preliminary vs Quantitative Experiments

Experimental rigor should increase with the maturity and scientific purpose of the experiment.

01

Exploratory experiment

Guiding question
Does the phenomenon exist?

A rapid, flexible test used to establish whether an effect is present and worth investigating systematically.

Quick assembly · qualitative observation · discovery of obvious failure modes
02

Quantitative experiment

Guiding question
How does output \(Y\) depend on parameter \(X\)?
Required foundation
  • Calibrated sensors
  • Controlled protocol
  • Repeatability
  • Synchronization
  • Raw-data preservation
  • Systematic processing
03

Publication-ready experiment

Guiding question
Can the result support a defensible scientific claim?
All quantitative requirements, plus
  • Uncertainty assessment
  • Replicate strategy
  • Traceable analysis
  • Complete metadata
  • Independent validation

The required rigor increases as the work progresses from exploration to quantitative inference and publication.

If repetitions disagree
  • Do not immediately average

  • Check correlation with time, temperature and trial order
  • Inspect repositioning, warm-up and sensor drift
Decision

Significant repeat-to-repeat differences must be understood before comparing parameter conditions.

A non-repeatable trend is not yet a reliable experimental fact.

Practical Checklist Before a Publication-Quality Run

You are responsible for the validity of every measurement. “Factory calibrated” is not evidence that the current measurement chain is correct.
Before acquisition
  • Calibration independently checked
  • Coordinate system defined
  • DAQ range and sample rate correct
  • Anti-alias filtering appropriate
  • Saturation and actuator limits checked
  • Camera synchronization validated
  • Environment recorded; experiment ID assigned
During acquisition
  • All data streams active
  • No clipping or saturation
  • Timing and trigger events correct
  • Commanded and actual inputs compared
  • Unexpected events recorded immediately
After acquisition
  • Raw file saved and readable
  • Metadata and notes saved
  • Quick sanity plot completed
  • File integrity verified
  • Raw file left untouched
